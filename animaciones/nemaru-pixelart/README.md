# Nemaru: sprites iniciales

Hoja de referencia de 6 columnas y 5 filas con espada azul.

Filas, de arriba abajo:
1. Quieto.
2. Corriendo.
3. Saltando.
4. Agachándose.
5. Atacando.

Este archivo es un borrador visual, no un paquete de animaciones terminado. Necesita limpieza del fondo, recorte y alineación de fotogramas y revisión de los ciclos antes de usarlo en un juego. No se garantiza transparencia del fondo ni uniformidad exacta de las celdas.

Se puede preparar para Godot (AnimatedSprite2D) o GameMaker (sprites con subimágenes). No contiene un modelo 3D ni un esqueleto.
